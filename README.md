# Nova Express for WooCommerce

**Nova Express** — плагін інтеграції служби доставки «Нова Пошта» для інтернет-магазинів на WooCommerce та WordPress.

## ✨ Основні можливості

- **Чекаут**: зручний підбір міста та відділення / поштомату (або адреси для кур'єра) з автоматичними підказками та збереженням у сесії та замовленні.
- **Сумісність із темами**: повна підтримка теми **Woodmart** (AJAX-оновлення, multistep checkout, власні поля) та класичного/блокового чекауту WooCommerce.
- **Адмінка замовлень**: чітке відображення міста та відділення/адреси як у рідному блоці адреси доставки WooCommerce, так і в метабоксі Nova Express.
- **Створення ТТН**: генерація експрес-накладних прямо з адмінки магазину або прив'язка вже створеного номера ТТН.
- **Друк маркувань**: друк стікерів (100x100 мм або A4) в один клік.
- **Трекінг та моніторинг**: фонове опитування статусів ТТН через WP-Cron із захистом від паралельних гонок.
- **Гнучкі автоматизації**: автоматична зміна статусу замовлення, додавання нотаток, відправка Email та вебхуків (включаючи сумісність із MacroDroid/Tasker) при зміні статусу посилки.
- **Вбудоване автооновлення**: перевірка та встановлення нових версій напряму з офіційного GitHub-репозиторію `kdinya/nova-express-woocommerce`.

## 📦 Формат версій

Версії плагіна відповідають стандарту: `РІК.МІСЯЦЬ.НОМЕР` (наприклад, `2026.09.1`).

## ⚙️ Встановлення

1. Завантажте архів `wc-nova-express.zip` з [останнього релізу](https://github.com/kdinya/nova-express-woocommerce/releases/latest).
2. У консолі WordPress відкрийте **Плагіни > Додати новий > Завантажити плагін**.
3. Оберіть завантажений архів і натисніть **Встановити зараз**, після чого активуйте плагін.
4. Перейдіть до розділу **WooCommerce > Nova Express: налаштування** та вкажіть ваш API-ключ Нової Пошти.
