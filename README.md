# Nova Express Woo for WooCommerce

Сучасний, швидкий та автономний плагін інтеграції доставки **Нова Пошта** для інтернет-магазинів на **WooCommerce / WordPress**.

---

## ⚡ Головні можливості

- 🚀 **Миттєвий чекаут**: локальна база відділень та поштоматів у базі сайту — клієнт обирає відділення без затримок та підвисань.
- 📦 **Генерація ТТН в 1 клік**: формування накладних із замовлення, підтримка типів вантажу (`CargoType`), вибір платника, друк маркувань.
- 🔄 **Автоматизації без абонплат**:
  - Автоматична зміна статусу замовлення при врученні посилки або відмові.
  - Вебхуки (JSON POST або GET для MacroDroid / Zapier / Make / n8n / CRM).
  - SMS та Email сповіщення за шаблонами з плейсхолдерами.
- 🎨 **Повна сумісність з темами**: безшовна інтеграція з Woodmart, Flatsome, Astra та стандартними темами WooCommerce.
- 🛡️ **Безпека та надійність**: захист від гонок при створенні накладних, строга санітизація, відсутність XSS.

## 📱 Безкоштовні SMS клієнтам через телефон (MacroDroid)

Плагін дозволяє автоматично надсилати покупцям SMS-повідомлення (про прибуття посилки у відділення, прибуття в поштомат, номер ТТН тощо) **без підключення платних SMS-шлюзів** (таких як TurboSMS чи SMS Club) і **без абонплат**:

### Як це працює
1. **Тригер у плагіні**: коли Нова Пошта фіксує потрібний статус (наприклад, *«[8] Прибув до поштомату»*), плагін активує дію автоматизації.
2. **Вебхук на смартфон**: плагін надсилає короткий запит на ваш Android-смартфон через безкоштовний додаток **MacroDroid**.
3. **Відправка через вашу SIM-карту**: MacroDroid миттєво зчитує номер телефону та готовий текст повідомлення й відправляє SMS через SIM-карту вашого телефону, списуючи безкоштовні SMS із вашого мобільного тарифу (Київстар, Vodafone, lifecell).

### Чому це вигідно та зручно
- 💰 **0 грн витрат на платні SMS-сервіси**: використовуються сотні вже оплачених SMS, що включені у ваш звичайний тарифний план.
- ⏱️ **Без бюрократії та модерацій**: не потрібно укладати договори, купувати альфа-імена чи чекати перевірки шаблонів.
- ⚙️ **Просте налаштування**: у вкладці плагіна **«Автоматизація ТТН»** обираєте режим *«Готовий текст SMS (для MacroDroid)»* та вказуєте URL вебхука з додатку MacroDroid.

## 📥 Встановлення та оновлення

1. Завантажте з [останнього релізу `v2026.09.09`](https://github.com/kdinya/nova-express-woocommerce/releases/latest) архів **`wc-nova-express.zip`** (розділ Assets), а не «Source code».
2. В адмінці WordPress перейдіть: **Плагіни → Додати новий → Завантажити плагін**.
3. Оберіть завантажений ZIP та підтвердіть заміну поточної версії.
