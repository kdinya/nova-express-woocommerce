# Чекаут та сумісність з темами

- **Адаптація до теми Woodmart**: поля вибору міста та відділення не мають сторонніх рамок, повністю успадковують шрифти та стилі теми оформлення.
- **Миттєвий вибір відділення**: пошук міст та відділень працює локально через індексовану базу без затримок та зовнішніх звернень до API на кожному кроці.
- **Кур'єрська доставка**: перемикач «Кур'єром за адресою» відкриває поля вулиці, будинку та квартири.
