# Автоматизації Nova Express Woo

Плагін підтримує два типи автоматичних сценаріїв:

## 1. Автоматизації ТТН (за подіями Нової Пошти)
Спрацьовують у фоні через WP-Cron при регулярному опитуванні статусів перевізника:
- Відправлення прийнято (статус 1 / 4)
- Прибуло у відділення (статус 7 / 8) -> надіслати SMS або вебхук клієнту
- Отримано (статус 9 / 10) -> автоматично перевести замовлення у «Виконано»
- Відмова або повернення (статус 102 / 103) -> перевести у «Скасовано» та сповістити менеджера

## 2. Автоматизації замовлень (WooCommerce)
Спрацьовують миттєво при зміні статусу замовлення в магазині:
- Зміна статусу на «В обробці» -> відправка даних у CRM або створення черги
- Перехід у «Виконано» -> фіксація в зовнішньому сервісі через вебхук

## Доступні дії
- **Нотатка до замовлення**: запис у хронологію замовлення з підтримкою плейсхолдерів `{waybill}`, `{status}`, `{order_number}` тощо.
- **Зміна статусу WooCommerce**: переведення замовлення у будь-який зареєстрований статус.
- **Вебхук (POST JSON / GET URL)**: інтеграція з MacroDroid, Zapier, Make, n8n, CRM.
- **Email-сповіщення**: гнучкі шаблони листів покупцю або менеджеру.
