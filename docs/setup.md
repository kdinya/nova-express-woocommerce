# Налаштування Nova Express Woo

## 1. Отримання API-ключа
1. Увійдіть до особистого кабінету [Нова Пошта](https://my.novaposhta.ua/).
2. Перейдіть у розділ **Налаштування** -> **Безпека** -> **Створити ключ**.
3. Скопіюйте згенерований 32-значний ключ.

## 2. Порядок початкового налаштування в адмінці
1. Вставте API-ключ у поле налаштувань.
2. Натисніть **«Синхронізувати базу відділень»** (ключ підхопиться автоматично без необхідності зберігати сторінку).
3. Після завантаження міст та відділень натисніть **«Отримати дані відправника»**.
4. Оберіть місто відправника та його базове відділення.
5. Натисніть **«Зберегти зміни»**.
